# claude-crew-statusline

Two small add-ons for [Claude Code](https://claude.com/claude-code):

- **Status line** — model, an animated activity indicator (thinking, writing, running, delegating, needs you), and color-coded bars for context window, 5-hour session and weekly limits.
- **Subagent crew pane** — a live "Agents" pane showing each subagent as a pixel-art Clawd whose hat reflects its effort level, with tokens, elapsed time, tool count and todo progress.

## Quick install

```sh
curl -fsSL https://raw.githubusercontent.com/juancho391/claude-crew-statusline/main/install.sh | sh
```

Needs `jq`. It backs up your `settings.json` once and merges into it (never overwrites). Options, passed after `sh -s --`:

| Option | Effect |
|---|---|
| `--statusline-only` / `--pane-only` | Install just one part |
| `--ref v0.1.0` | Install a tag or branch instead of `main` |
| `--uninstall` | Remove the files and the settings entries it added |

Prefer to read it first? `curl -fsSL <url> -o install.sh`, inspect it, then `sh install.sh`.

## Install with an agent

Paste into Claude Code (or any coding agent) from a clone of this repo:

```text
Install this repo into my Claude Code setup and verify it works, following AGENTS.md
```

[`AGENTS.md`](AGENTS.md) has the full steps: backup, idempotent settings merge, verification and uninstall.

## Status line

Requires `jq` and a 24-bit-color terminal.

```sh
cp statusline/statusline.sh statusline/statusline-state.sh ~/.claude/
chmod +x ~/.claude/statusline.sh ~/.claude/statusline-state.sh
```

Then merge `statusline/settings.example.json` into `~/.claude/settings.json` (keep any hooks you already have; add these entries alongside them).

How it works: hooks call `statusline-state.sh`, which writes the current activity per session to `~/.claude/statusline-state/`. The status line re-runs every second (`refreshInterval: 1`) and picks the animation frame from the clock.

## Subagent crew pane

```sh
cp -R mods/subagent-crew ~/.claude/mods/
```

Point Claude Code at it with the plugin dir setting in `~/.claude/settings.json`:

```json
{ "env": { "CLAUDE_CODE_PLUGIN_DIRS": "~/.claude/mods/subagent-crew" } }
```

Run `/crew` to open the pane. Subagents also get a `report_progress` tool so the pane can show per-step progress.

`tsconfig.json` extends `.claude-plugin/types/tsconfig.json`; the `claude-code*` type packages in that folder are generated by Claude Code and are git-ignored.

## Layout

```
statusline/            status line script, hook helper, settings example
mods/subagent-crew/    the pane plugin (hooks, sprites, tests, types)
```
